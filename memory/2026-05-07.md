## Algorithm Findings

- Monolithic Gurobi is still much faster than the tested Benders variants on the current Meituan instances.
- Outer-loop Benders supports primal and dual subproblem variants, Pareto / Magnanti-Wong cuts, timing metrics, and trust region.
- Trust region is not universally beneficial. Without a good initial solution it can slow convergence.
- Callback Benders should use the dual subproblem only, with persistent dual / MW / recession contexts.
- Local-search heuristic is useful mainly as an incumbent generator or quick evaluator, not as an optimality proof.
- At 100 physical Meituan candidates (`H=60, L=20, E=20`), fixed local-search evaluations are fast, but the current default seed enumeration creates 5083 initial candidates and should be capped or redesigned before full-scale experiments.
