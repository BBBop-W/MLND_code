# 当前模型：consecutive

基准是本次用户提供的 1,892 行 LaTeX 附件，特别是 372–1320 行模型及算法。2026-10-15 按用户要求增加完整路径兼容性筛选，并将新场景默认设为聚合任务流松弛；附件的逐首段约束保留为可比较的 `prefix` 设置。所有持续时间统一使用小时，订单/任务率使用每小时，费用使用同一时间尺度。

## 设计与任务重构

二元设计包括基地/柜点开设、柜格容量档、OD 到基地对的分配以及有向航段开设。基地对允许相同起终基地。每个 OD 至多分配一个基地对：sum_b a_rb <= 1，不要求分配。a_rb=1 且 rho_l=0 时服务量仍可为零；正需求、a_rb=1、rho_l>0 时服务量 h_r*rho_l 必为正。

对一个分配池，令 h 为原始需求率，a 为二元分配：

- lambda = sum(h*a)，pi = h*a/lambda，q = 1-exp(-lambda*delta)。空池所有率置零。
- theta_r + q*pi_r*sum_s(kappa_sr*theta_s) = h_r*a_r。
- 单任务率 nu_r = theta_r*(1-q*sum_s(kappa_rs*pi_s))。
- 双任务率 nu_rs = theta_r*q*kappa_rs*pi_s。
- 同 OD 双任务计两次订单；每个 OD 的单任务、第一单和第二单总量保持原始需求。

kappa 可非对称且对角线可正。新场景默认先按 all/distance/matrix 规则提出兼容项，再保留至少有一条物理可行完整双单路径的项；已给定的非零小数系数保留原值。完整路径同时检查逐单送达期限、整趟运行时限、窗口、候选柜点与航段。筛选在固定候选网络上、优化分配前完成，随后冻结 kappa，不随当前选址解或流量重算；历史输入原样回放。全网存在不等于每个基地对都存在，诊断记录各基地对覆盖，实际选择仍须通过路径及设施约束。兼容性筛选改变需求重构参数，不是单纯数学松弛。

配对概率 q*kappa*pi、独立 Poisson 任务流及共同基地可用率仍是所采用的规划近似。为保证 K1/K2 对照口径相同，生成兼容矩阵时统一使用配置的 K2 窗口及物理条件。

## 实际流量与首段策略

`flow_policy="prefix"` 对应附件：首段在得知第二 OD 前选定，执行率 H；辅助 eta 满足 lambda*eta=q*H。每个首段的单分支和每个兼容第二 OD 的双分支保留等式：

- 单单：sum(psi_single) = H - sum_s(kappa_rs*h_s*a_s*eta)。
- 双单：sum(psi_double_s) = kappa_rs*h_s*a_s*eta。
- 各 OD 初始服务和续单服务总量 = h_r*a_r*rho。

没有第二单转骑手的路径分支。若一个必须满足的双分支没有任何物理可行路径，则相应等式仍保留，可能迫使首段 H=0。所有设计都有 rho=0、所有订单直接骑手服务的可行后备解。

`flow_policy="aggregate"` 为新场景默认的聚合任务松弛。对固定基地对 b、首 OD r，将上面单/双分支等式在所有相同 (b,r) 的首段上求和，只约束任务总量，不再规定每个首段的续单构成。每个首段仍满足 H=sum(实际使用该首段的完整路径流)。固定分配后严格得到：

- sum(所有 r 单单路径流) = rho_l * nu_r。
- sum(所有 r→s 双单路径流) = rho_l * nu_rs。

聚合松弛可以让 r→s 和 r→t 选择不同第一程；不强制第一程最短，也不删除订单守恒、共同 rho、完整路径可行性或资源约束。同一输入下 prefix 的可行解必可映射到 aggregate，因此后者的最优费用不高于前者；K=1 两种策略等价。此松弛允许路线选择依赖完整任务类别，尚不能作为原先“第二单之后才出现”时序下的可执行在线策略证明。

独立运营核验按输入策略检查：prefix 检查每首段比例，aggregate 独立重算 nu 并核对每个单单/有序双单类型的总流量。只对齐每个 OD 总量还不够。同一正需求任务若在选定基地对下没有任何路径，即使 aggregate 仍会通过 0=rho_l*nu 迫使共同 rho_l=0；优化可以通过不分配相关 OD 避免。

二元乘积 v=a*rho、u=a*eta 和 H 的指数链采用有界精确线性化；固定二元设计后，子问题公共矩阵保持不变，只有设计固定行的右端变化。

## 时间、资源与容量

下一单请求发生在第一载货腿结束前 delta 时间内。V 为下一单请求到第一单投柜的时长，采用 Uniform[0,delta]，独立于骑手时间和条件路径标记。delta 不超过任何允许首段的第一载货腿时长；K=1 的有效 delta 为零。

骑手前段时间为给定均值的指数分布；零均值按确定性零的连续极限处理。记 t0 为基地到首取货柜时长、t12 为第一投柜到第二取货柜时长：

- w1 = r1*exp(-t0/r1)，Q1=t0+w1。
- w2 = r2*exp(-t12/r2)*(1-exp(-delta/r2))/(delta/r2)。
- Q2=t12+delta/2+w2。
- tau=总飞行时间+w1+w2；单单仅含 w1。

每个订单从自己的请求起计时，Q_n+载货飞行时间+receipt_mean <= deadline_r。tau <= operating_limit。空调位只计飞行时间。装卸和回基地补能周转按附件忽略。

取货柜预约占用 Q_n；投递柜预约占用 Q_n+载货飞行时间+removal_mean。receipt_mean 是最终收货终点，removal_mean 是餐品离柜终点，分别按给定客户选择概率加权。多单或重复柜的占用逐次相加。

基地流量守恒；机队满足 sum(I)+sum(tau*psi)+sum(tau_empty*phi)<=Gamma，以及 I>=rho/(1-rho)。柜位采用 Poisson 潜在负荷超限阈值。均值送达限制不解释成准时概率，Poisson offered-load 超限不解释成真实阻塞概率。

## 路线域与证书

- direct：每个服务腿只使用直接候选航段。
- simple：枚举每个腿的全部 elementary 路线，不能重复访问该腿内节点；不同服务腿可重复物理节点。
- supplied：只使用显式提供的有限 elementary 腿路线集合；同柜转接的零腿隐含可用，不自动补充其他直飞腿。

路径按相同物理检查生成并验证。超出目录/时间预算不会返回一个标称 complete 的截断集合。

CG 保留全部首段及分支行，仅增减完整路径的标量流列；对包括关闭设施、关闭航段和未选 OD 的整个候选目录定价。全局割来自公共矩阵显式 SOCP 对偶，包含界与锥贡献、数值残差修正和遗漏列定价修正。定价不完整不发新割。

显式有限变量上界利用非负运营费用、正机队费用及全骑手后备成本，保留每个设计的运营最优值；空流按无环最优代表限界。当前版以该完整 lifted 模型为证书基准，不使用旧资源矩、rider 聚合或 fixed-design 数值对偶冒充全局割。
