# L2 可行设计改进

`--primal-polish` 是默认关闭的启发式选项，不改变完整模型、需求构造或 Benders 割的认证条件。它适用于现有 `restricted_mip` 搜索；关闭该搜索时不会单独启动。

## 原因与实现

原实现调用 `solve_restricted_heuristic` 时使用全部已注册路径。在预处理广义任务模式中，注册目录已经是完整物理路径集，因此“generated_column_mip”也可能是完整路径 MISOCP。原先每次最多 15 秒、每次重建，真实 L2 试验留给优化器的时间约为 7–10 秒。固定流量的资产清理只能删除零流量资产，不能通过重路由关闭资产。

新搜索使用

\[
\mathcal P^{H}=\mathcal P^{CG}\cup\{p:\bar\psi_p>0\},
\]

空载列作相同处理。这里的 CG 集合是运行中实际积累的列池，第二项保留当前可行解的全部严格正流量支持。不以流量阈值删掉小流量，不删掉缺少列的任务等式。

第一次有无人机服务的调用固定当前订单分配，联合优化设施、容量、航线、路径流量、基地可用率和机队规模，单次上限 60 秒。之后与不固定分配的 30 秒调用交替；原有局部邻域搜索保留。所有调用都受原有总启发式预算（默认总时限的 20%）及全局剩余时间限制。

## 有效性边界

由于保留全部正流量支持，当前可行解仍属于所选列的可行域；固定分配时也保留其当前分配。新 MIP 允许流量自行调整、归零，从而关闭资产。输出必须通过原矩阵和独立物理约束检查后才可更新全局上界。

这是原模型的可行子集。受限 MIP 的最优值、best bound 及固定分配邻域的 best bound 均不能直接作为完整模型下界。代码不将它们写入 Benders 下界；候选设计若用于生成割，仍需经过原完整定价与证书流程。上界改善可能通过 incumbent cutoff、warm start 和原自适应控制间接改变后续下界轨迹。

## 代码和记录

- `cpp/src/heuristics.cpp`：可选列选择、正流量支持补全、固定分配、原约束验证。
- `cpp/src/benders.cpp`：传入实际列池，安排调用预算，接受可行上界。
- `cpp/tests/primal_polish_probe.cpp`：L1/L2、单单/双单回归，缺失必需任务分支、固定与释放分配、索引与上界有效性。
- `primal_design_polish_records`：逐次预算、全局时间、实际列数、分配是否固定、前后 UB、求解节点和验证结果。

正式对照使用 `outputs/l2_primal_improvement_20261027`：同一新二进制、相同公共加强、600 秒、单线程、seed 43，唯一开关差异为 `--primal-polish`。旧批次仅作历史参考。结果以该目录最终报告和验证状态为准。
