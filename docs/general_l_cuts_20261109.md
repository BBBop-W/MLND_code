# 任意基地数的设计面割与双任务联合队列割

本次基于当前任务级独立出发基地指派模型。实现仅包含单任务设计面割与双任务联合队列割，不包含三任务联合割。数值结果及完整验证记录见 `outputs/general_l_cuts_20261109/REPORT.md`。

## 模型口径与对加速的影响

当前 `preprocessed` 模型的分配变量为 `alpha[q,l]`：每个单订单或有序双订单任务独立选择出发基地。任务 q 的路径流量之和等于 `nu[q]*alpha[q,l]*rho[l]`，求和覆盖所有可行返回基地。返回基地由运营路径决定，空载调位与基地流量平衡继续保留。任务 ID 是 R 个单任务及随后 R² 个有序双任务；零需求任务的指派固定为零。

这包含两个不同变化：一是从基地对指派变为仅出发基地指派，二是从同首单任务捆绑变为独立任务指派。当前源码在本轮前已完成这些迁移，本轮不再更换模型。不同返回基地的路径仍然不同，不能因没有返回基地指派变量而把其物理资源列合并。

普通 Benders 对偶割、按任务构造的资源下界和基地队列 EPI 保留有效性；路径最小成本必须遍历所有返回基地，收益与缺路径门控必须按单个任务定义。完整定价的遗漏列修正为 `sum_q nu[q]*max_l[-min(0,rc_min[q,l])]`，不能复用旧首单分组的聚合顺序。航线界采用各任务分别对基地取最大后求和。缓存需包含当前任务率与物理路径域身份，旧基地对或旧首单捆绑设计及其证书不能复用。

当前模型已经满足上述要求，相关代码在 `input.hpp`、`formulation.cpp`、`task_savings.cpp`、`pricing.cpp`。ALNS、支持补齐及 CG 向 ALNS 的反馈仍限 L2 K2。本轮比较对全部 L2/L3 同时关闭 `primal_alns`、`primal_support_completion`、`indexed_support_completion`、`cg_primal_feedback`，保持上界配置一致；其他既有加速保留。

## 设计面割

任务 q 有 L+1 个互斥穷尽状态，`z[q,0]=1-sum_l alpha[q,l]`、`z[q,l]=alpha[q,l]`。在状态 s 上固定全部 L 个指派位，其余设计连续自由，使用完整域 CG 下界证书 b[q,s]，其中包含固定建设成本。缺证书时回退已认证全局总成本下界 B；有效面下界与 B 取最大。

加入 `C_fixed(d)+theta >= sum_s b[q,s]*z[q,s]`。任意整数设计恰落一个状态，右端等于该状态的认证下界，故线性不等式对整数上图及其凸包有效。不同任务的总成本下界不能相加。

实现把状态容器、状态边界、固定行数量、候选评分与结果元数据一起推广。证书检查任务指派口径、基地数、L+1 状态数、L 条固定行、其他设计自由，以及完整定价修正。既有 L2 评分与公式保留，K2 模型范围及调用预算不变。

## 双任务联合队列割

固定合法资源价格，队列下界写为 `Q(d)>=K_lambda(d)+sum_l h_l(A_l)`。支持完整时 `h_l(A)=-Phi_F(sum_{q in A} B[q,l])`；若集合包含在该基地缺路径的任务，则该基地可用率被迫为零，队列项为零。

仅选择两个任务，构造完整 `(L+1)^2` 状态表 H。系数 LP 最大化当前分数点处的 `beta0+beta*alpha`，并对每一个状态施加该仿射值不超过 H 的约束。主问题不增加运营或状态变量。L2 保留原五系数、九状态面枚举；其他 L 使用 `2L+1` 系数的单线程 LP。

LP 仅提供候选系数。先扫描全部状态计算最大超差，再扣减截距及数值保护量，最后再次检查全部状态。任何扫描未完成均不返回有效割，不将该 LP 的目标或 best bound 当作原问题下界。证书分别保存系数 LP 调用、最优状态和全表验证状态。

对选中集合外的正收益任务，按 `Gamma[q,l]=Phi_F(P_l)-Phi_F(P_l-B[q,l])` 扣减，其中 P_l 是全部支持完整任务正收益之和。Phi 的凸性保证每次加入该任务造成的成本下降不超过 Gamma；负收益任务或缺路径任务只会提高队列项，故无需扣减。逐个加入外部任务即证明全局提升有效性。

纯非负且支持完整的双任务表在任意 L 下可由最大耦合同时实现各基地的逐基地凸包，因此不额外分离。L2 的补变量奇偶筛选只用于 L2；其他 L 保留有符号或缺路径候选。三任务循环冲突不在本轮范围内。

## 验证与比较口径

源码基准是本轮开始的同一任务级模型，提交 `5d1731d382fd100bc37dd62a38fc97c3d5d9698c`，快照位于输出目录 `before/`。修改前后独立构建，各运行使用相同 CSV/2 输入、K2、seed43、单线程、30秒上限及相对 gap 1e-6。各 3 个 L2/L3 小例，另运行完整路径 CPLEX 作为参考，共18次最终求解。小型验证不代表大实例加速。

有效性检查包含 L1/L2/L3 设计面证书与完整物理面参考，L3/L4 联合割全部局部状态和四任务全部整数指派，独立 Python 全路径收益与资源价格重建、状态与提升系数复算，以及求解结果的物理校验。分数点上严格加强不等于生产实例最终认证下界必然提高。

并行编辑期间有一次构建读取到最终元数据编辑之前的 benders.cpp，初步结果及二进制完整保留在 `pre_final_build/`。源码冻结后强制重新编译该文件，并重新执行修改后算法与 CPLEX；正式报告仅使用最终构建结果。未覆盖历史批次或修改模型迁移材料。
