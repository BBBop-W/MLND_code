# 上下界改进：有效弱割、内部点分离与互补原始邻域

三项为可选算法改动，模型、需求重构、路径可行域与认证容差不变。普通对偶继续从原 SOCP 的 CPLEX 解直接读取。

## 有效性与紧性分开

设固定设计运营值为 Q(x)。原生乘子经符号、锥及有限变量界残差修正后，给出受限列模型的仿射下界 a+βx。完整定价给出的遗漏列修正为 Δ≥0，则 a−Δ+βx≤Q(x)，对原设计域中所有 x 成立。该弱对偶结论不要求乘子在当前设计达到最优。

`--weak-dual-cuts` 在每次完整定价后保留当前设计处最强的修正割；负约化成本路径仍继续加入。没有可加列但原始—对偶差距未达到原容差时，返回 `weak_dual_bound`。`bound_valid`/`pricing_complete` 表示已获得完整路径域上的有效下界，`recourse_optimal` 独立表示达到原紧性要求。有效弱割不用于宣称子问题最优，也不用于排除整个设计。未完成定价不能产生新的全域割；此前已认证割仍可保留。Pareto 最优面选割只接受紧锚点。

## 内部设计处的分离

`--interior-cuts` 在整数阶段下界停滞或当前证书不紧时，对 x̃=0.9x+0.1c 求解原连续运营模型，c 为既有可行参考点。凸组合仍在原设计松弛域内。完整定价后获得的仿射割是全局运营值下界，可加入同一整数主问题。Q(x̃) 本身不作为全局下界；全局下界只在重求主问题后更新。这个步骤求解另一个原始运营 SOCP，没有自建普通对偶 LP。

最多使用总时限5%，每次最多5秒，第一次在五次整数运营评估之后触发，此后至少间隔十次。记录生成点、完整定价、当前候选处割值、实际耗时及新增割数；没有普遍优于边界点割的保证，效果由相同算例比较判定。

## 上界邻域

`--primal-asset-neighborhood` 与 `--primal-polish` 联用。原固定分配搜索释放资产和运营；互补搜索固定当前可行解的设施及容量，释放分配、航线和运营。两种模式交替，总启发式预算仍为20%。每次搜索保留原运营约束和正流量路径，只接受原模型验证通过的整数可行解；受限路径 MIP 的 best bound 不进入全局 LB。

## 验证与复现

`weak_dual_probe` 使用测试专用紧容差触发原生有效但不紧证书，检查完整定价、跨设计弱对偶及独立最优性标志；生产容差不变。`primal_assets_probe` 检查资产保持、分配改善及原模型可行性。继续运行完整连续/整数集成与既有跨设计割检查。

固定基准为本轮前原生对偶版本，快照及哈希见 `outputs/bounds_improvement_20261028/before_manifest.json`。正式比较使用现有 TSL L02 M01/M07/M08，600秒、seed43、单线程、目标gap1%。lower开启前两项，combined再开启原始邻域；历史同设置原生对偶运行仅作为明确标记的冻结基准。结果按实际终止、UB、认证LB、gap、阶段耗时和模型规模汇报。
