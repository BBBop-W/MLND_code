# 固定广义任务模型的路径支持过滤与支配割

本说明适用于 `preprocessed_demand=true`、出发基地分配、`aggregate` 流量策略以及关闭 `first_leg_consistency` 的当前模型。单单、双单共用这一逻辑。运营子问题、固定任务率、电量与时效路径筛选规则均保持不变。

## 约束的有效性类型

这里的支持约束不是原战略变量空间上处处成立的 valid inequality。原模型允许已分配任务在基地可用率为零时全部转由骑手配送，因此一个没有无人机路径的分配编码仍可能是原模型的可行解。

新的约束选择一种不保留空分配的表示，保留原模型的最优值及其运营结果投影。应称为保持最优性的支配约束（optimality-preserving dominance restrictions），而不能把原 SOCP 子问题有骑手兜底的情况写成数学不可行。新模型的连续松弛可能不同于旧模型；它的下界仍适用于原整数最优值，但不能称为原连续松弛值。

## 定义

令 `alpha[r,l]` 表示将头订单类型 r 分配给出发基地 l，`rho[l]` 表示该基地的可用率。当前代码使用

\[
\sum_l\alpha_{rl}\le 1,\qquad
v_{rl}=\alpha_{rl}\rho_l
\]

且 alpha 没有直接目标系数。单单率 `nu[r]` 和双单率 `gamma[r,s]` 在求解前已固定，不随分配改变。

定义正任务集合

\[
\mathcal T_r=\{(r):\nu_r>0\}\cup
\{(r,s):\gamma_{rs}>0\}.
\]

对于任务 t 从基地 l 出发，`P[t,l]` 是完整物理可行路径集，包含所有返回基地。每条路径已经通过现有时间、电量代理和订单时效检查；路径集并非当前 RMP 已加入的列集。

## 命题：零可用率基地的分配可以同时清除

对任意原模型可行解，把所有满足 `rho[l]=0` 的基地对应的全部 `alpha[r,l]` 置零，保持所有其他变量不变。所得解仍可行、目标值不变，且若剩余 `alpha[r,l]=1`，则每个 `t in T[r]` 都至少有一条开放路径。

证明：原本 `v[r,l]=alpha[r,l]rho[l]=0`，清除 alpha 不改变 v。分配总和上界和分配到开放基地的约束仍成立，整数分配乘积线性化也仍成立。单单、双单及头任务总流量等式的右侧不变，因此可以保持全部路径流量。第二单的实现量由实际路径贡献，不由它自身的 alpha 决定，所以从其他头任务进入的第二单服务不变。柜占用、基地流平衡、空载调位、机队、库存、设施和航线均可保持原值。alpha 不直接进入目标，因此成本不变。

对剩下的 `alpha[r,l]=1`，必有 `rho[l]>0`。每个正任务 t 的总流量等于其正率乘 `rho[l]`，因而至少一条对应路径具有正流量。航线流量上界强制这条路径的所有航线开放。该变换同时满足全部任务支持要求，而不是为每一条割分别寻找不同的修复。证毕。

该证明不要求关闭基地，不改变返回该基地的服务路径或调位流，也不人为给 rho 加正下界。

## 静态过滤

若某个正任务 `t in T[r]` 满足 `P[t,l]` 为空，则固定

\[
\alpha_{rl}=0.
\]

原来 `alpha=1,rho=0` 的冗余编码可以违反这条约束，但有同运营结果、同目标值的规范化编码。对零任务率不要求路径；特别是 `nu[r]=0` 时不能因为没有单单路径而删除分配。所有返回基地必须联合检查，不能沿用旧基地对索引只检查一个返回点。

## 动态路径支持割

对当前整数航线设计 y，若任务 t 没有开放路径，取当前关闭的航线集合 C，满足

\[
E(p)\cap C\ne\varnothing,\qquad\forall p\in\mathcal P_{t l}.
\]

这里 `E(p)` 是路径所用的不同航线集合。加入

\[
\alpha_{rl}\le\sum_{e\in C}y_e.
\]

证明：规范化解中，若 alpha 为一，任务有某条完全开放路径。C 命中该路径，因而 C 中至少一个 y 为一；alpha 为零时约束自动满足。命题已经证明所有规范化约束可同时加入而保持最优值。

这一割不要求其他订单采用当前分配，也不固定其他无关设施。打开一条阻断航线只是一项必要条件，未保证立刻产生开放路径；后续分离会继续补充必要条件。若完整路径集为空，C 为空，退化为静态过滤。AA 双单仍是一类路径任务，需求守恒中的两次 OD 出现不改变该支持逻辑。AB 任务的触发分配为其头订单 A 的 alpha，不是 B 的 alpha。

## 计算与数值边界

- 缓存只接受 `paths.complete && paths.support_complete`。有限行支持完整不能替代完整物理路径目录。
- 分支纳入条件采用实际存储率严格大于零；不通过任意阈值删除小的正需求。
- 先扫描完整路径族，证实每条路径都有关闭航线，才可以出具阻断证书。扫描超时不能把未找到路径当作没有路径。
- 阻断集缩减只删去仍保留全部路径覆盖的航线；缩减超时可退回已经认证的较大集合。
- 当前分离接口只接受整数设计。即使由整数点产生的行可以用于规范化模型的 LP 松弛，也不能把它误称为原分数模型上的冗余行。
- 这些检查不证明柜容量、机队或跨基地流量平衡可支持正服务，仍需原 SOCP/CG。
- 数学证明的零可用率是精确的零。构造数值热启动时，不得把近零 rho 任意清零却保留不相容的正路径流量；必须重新验证完整原模型。

若以后改为必须分配、让需求重构依赖 alpha、给 alpha 直接收益，或者更换首段一致性语义，须重新证明，不能仅复用开关。

## 验证程序

`cpp/tests/path_support_probe.cpp` 使用已有两 OD 物理 fixture 的相同数据结构，作为单元验证，不生成新的生产实验实例。

验证包括：

1. 构造原模型可行、零可用率但有分配的全骑手点，证明它可以违反支持行；同时清零对应 alpha 后，原完整矩阵仍满足，运营变量及目标保持完全不变。
2. 构造从基地 0 服务、只可返回基地 1，再由空载路径返回基地 0 的正服务点；其中包括 AA 和 AB，B 没有自身的基地分配。检查原矩阵及支持检查均接受。
3. 枚举 L1/L2 fixture 的全部服务航线开关，直接扫描完整 `ServicePath` 对象，与分离结果交叉核对；逐条检查阻断集确实命中对应任务的所有物理路径，且只含关闭航线。
4. 检查目录不完整、支持不完整、预处理/分离超时、零割预算、分数输入和零单单率等边界。
5. 在 L1/L2、单单/双单、正常/存在物理不可行 OD 的八种小 fixture 上，比较原全路径 MISOCP 和加入静态及全部已枚举支持割后的全路径 MISOCP，均要求求到最优、原始残差通过，并比较目标值。
6. 使用冷启动、关闭启发式的两组短时 Benders 集成测试，分别要求真正加入动态支持割与静态过滤，检查输出诊断、无新增变量以及算法认证下界不超过同一 fixture 的全路径整数最优值。

构建入口遵循现有通用 probe 规则：

```bash
make -C cpp BUILD_DIR=build-unified build-unified/mlnd_path_support_probe
cpp/build-unified/mlnd_path_support_probe
```

生产实验的运行参数、上下界和性能结论由本次独立实验记录给出，不能从理论有效性或单元验证推断加速幅度。

2026-10-27 的独立模块验证记录位于 `outputs/path_support_validation_20261027/probe.json`。八组全路径对照均达到最优，最大目标差为 `1.78e-8`（数值求解误差量级）；枚举并检查了 8,448 个航线网络/分配组合，进行了 70,884 次逐路径阻断覆盖检查。原可行全骑手点对支持行的违反量为 1，规范化后保持同一运营点和目标值；跨基地返回与第二单未分配的正服务见证也通过完整原矩阵残差校验。该记录不包含生产算例的性能结论。

两组端到端短时检查也通过：正常双单 fixture 实际加入 12 条动态割，跳过 3 次原本要进行的整数子问题求解，最终 UB/LB 为 `41.8950007441 / 41.8949988829`，对照全路径最优值为 `41.8950006592`。静态缺路径 fixture 加入 2 条过滤与 12 条动态割，最终 UB/LB 为 `148 / 147.99999851`，对照最优值为 `148`。两组均未新增主问题变量；静态过滤后的根界明确标记为 `optimality_preserving_support_root`。

## 方法出处与本模型的适配

- Codato and Fischetti (2006), *Combinatorial Benders' Cuts for Mixed-Integer Linear Programming*, Operations Research, DOI `10.1287/opre.1060.0286`。借鉴冲突集合和组合割的构造，以及对冲突集合的缩减。作者全文：<https://www.dei.unipd.it/~fisch/papers/combinatorial_benders_cuts_for_milp.pdf>。
- Ciré, Çoban and Hooker, *Logic-based Benders Decomposition for Planning and Scheduling: A Computational Analysis*，作者稿式 (11) 及其后的冲突任务集缩减。借鉴“先分配、后检查运营支持、提取较小失败原因”的流程。作者全文：<https://johnhooker.tepper.cmu.edu/bendersCOPLAS.pdf>。

文献中的不可行子问题与本模型允许骑手兜底的结构不同。前述零服务分配规范化命题是本实现需要自行补充的有效性桥梁，不能说文献已经证明当前 MLND 的具体支配约束。

## 分数路径支持 LP 分离

以下强化沿用上面的同一规范化模型、正任务分支和完整物理路径目录，不改变固定任务率、运营流量等式或路径可行性。与原整数阻断检查不同，它可以在分数主问题点分离。

对每个正任务分支 t、头订单 r 和出发基地 l，以 E(p) 表示路径 p 使用的不同航线集合。给定航线变量 y，定义外部支持函数

\[
z_{tl}(y)=\max_{w\ge0}\left\{\sum_{p\in\mathcal P_{tl}}w_p:
\sum_{p:e\in E(p)}w_p\le y_e\quad\forall e,
\quad\sum_p w_p\le1\right\}.
\]

这些 w 是外部存在性检验的归一化权重，不是新增运营流量，也不进入主问题。规范整数解若 alpha[r,l]=1，则该分支至少有一条全部航线开放的完整路径；令对应 w=1，即得 z=1。alpha=0 时 alpha<=z 恒成立。因此所有规范整数解及其凸包满足 alpha[r,l]<=z[t,l](y)。

支持 LP 的对偶为

\[
\min_{\eta\ge0,\xi\ge0}\ \sum_e\eta_e y_e+\xi,
\qquad
\sum_{e\in E(p)}\eta_e+\xi\ge1\quad\forall p\in\mathcal P_{tl}.
\]

任意覆盖完整路径域的对偶可行系数均给出线性行

\[
\alpha_{rl}\le\sum_e\eta_e y_e+\xi.
\]

无需取得 LP 最优值才可输出行，但必须验证对偶可行性。所有系数上界设为 1 不损失该分离 LP 的最优值：任意大于 1 的非负 eta 或 xi 截为 1，仍覆盖其参与的每条路径，且在非负 y 下目标不会上升。计算时只保留该组路径使用的航线价格。

原阻断集 C 对应 xi=0、eta[e]=1[e in C]，所以是本类行的特例。更一般的分数价格可以更强：假设三个路径支持集为 {a,b}、{a,c}、{b,c}，在 alpha=1、三个 y 均为 0.5 时，任何最小整数阻断集都只给 alpha<=1；而 eta[a]=eta[b]=eta[c]=0.5、xi=0 给 alpha<=0.75。这个代数例子说明分数分离有额外能力，不构成生产算例加速结论。

### 完整域证书与数值处理

- 复用 `PathSupportCache`，仍要求完整物理目录和完整支持，包含全部返回基地，只对严格正任务率建组。每条路径的航线按 presence 去重；重复经过同一航线不得在存在性 LP 中重复消耗其 y，否则会引入错误的额外运力限制。
- 外部 LP 包含该分支完整缓存中的每条不同支持路径，既不是当前 RMP 列集，也不是有正运营流的路径集合。
- 对候选价格先投影到非负，然后扫描完整路径集，将 xi 增大到至少 max(0,max_p(1-sum_e eta[e]))。对导出的 double 截距作向上舍入及 1e-12 量级保守余量，再次扫描全部路径确认覆盖和不等式方向。未完成扫描、非有限价格或无完整目录时不输出有效行。
- 修复只能使行更弱，不会把未认证的受限列对偶当作全域证书。元数据保留修复前缺口、最终最小路径覆盖、所有非零航线价格、截距、扫描路径数，以及完整导出行。
- 行的有效域仍是规范整数设计及其凸包。它可以强化主问题的分数松弛，但不是原始分数运营模型中的冗余不等式。不得把加入这些行之后的根界误标为未经规范化的原连续松弛值。

### 预算、缓存与检查

`FractionalPathSupportSeparator` 引用生命周期内不变的 Input 和完整支持缓存。`separate(design, absolute_deadline, max_cuts)` 接受绝对截止时间和最大输出行数；`FractionalPathSupportOptions` 进一步限制每次 LP 时间、每次调用最多 LP 数、最多缓存 LP 数及分离违反阈值。对象按组轮转起点，避免持续只扫描最前面的任务组。缓存按最近使用顺序淘汰，默认至多 8 个 CPLEX 模型，而不是为所有任务长期保存独立环境。

先检查单条路径能否承载 alpha，并构造一个贪心可行分数 packing。如果可行 packing 已达到 alpha，则 z 的下界已足够，直接跳过 LP。这个跳过只用于节约分离时间，不产生下界或割证书。剩余组才求外部 LP，并通过前述完整扫描出具证书。扫描/构造/LP/证书均使用同一总截止时间；LP次数或行数达到上限不意味着完成了全域分离，报告明确 `complete_separation=false`。

针对性测试入口为 `cpp/tests/fractional_path_support_probe.cpp`，可通过现有通用 probe 规则构建，无生产实例求解批次。测试复用已有物理 fixture，覆盖三路径严格分离例子、所有支持规范整数点检查、完整路径修复遗漏路径的候选价格、负价/NaN/超时、零预算、模型缓存复用、实际 AA/AB 路径及跨基地返回。物理见证通过每条完整支持路径核对导出行，不要求第二个订单具有自己的分配变量。
