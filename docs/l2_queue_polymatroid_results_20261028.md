# L2队列割：构造、实现及完成后的新旧比较

日期：2026-10-28。结论：三个预先指定的L2实例认证下界均提高；原算法三例在600秒内均未达到1%，新算法M01和M07分别约83秒、472秒达到1%，M08在600秒结束时gap为1.0247%。这是本批固定seed的完成结果，不是普遍速度保证。

## 实现了什么

新开关 `--queue-polymatroid-cuts` 默认关闭。`cpp/src/queue_polymatroid.cpp` 实现零价格EPI和资源定价EPI；`airline_resources.cpp` 导出已有资源LP的价格，`benders.cpp` 接入根、整数候选及既有支持根刷新。主问题只加线性行，保留旧割、原模型和完整路径定价认证；新割不触发跳过当前候选的完整recourse。

令F为机队成本，S为基地获得的总任务净收益。精确消去共享可用率得到队列收益

\[
\Phi_F(S)=0\;(S\le F),\qquad \Phi_F(S)=(\sqrt S-\sqrt F)^2\;(S>F).
\]

对二元首单分配构造次模函数的前缀边际，并按当前分配值贪心排序，生成有效线性下界。资源定价版先在完整路径上重算每个正需求分支的最小调整成本，形成signed B和资源常数项K；负B用补变量展开，缺路径组用必要AND门控，负调价空返用有限D*y域修正。详细推导与有效域见 [设计稿](l2_queue_polymatroid_cut_design_20261028.md)。

每个新价格profile最多1秒完整扫描，未完成不提交；最多缓存8个profile，始终保留EPI-0。缓存后分离只需每基地一次50项排序。每轮最多一条、总计最多1000条新行。价格来源目前为已有航线资源LP；普通SOCP原生对偶入口及第二路线设计面残差割未实现。本轮没有消融或固定master快照实验。
