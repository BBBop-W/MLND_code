# 完整任务成本、柜格负载与航线界：有效性说明

本次只强化现有的固定广义任务模型，不重新构造需求，不修改分配、连续接单、共同基地可用率或柜格占用的运营含义。主问题仍只有战略整数变量及运营成本 epigraph `theta`；原有连续运营子问题仍为 SOCP。任务资源 LP 是用于分离有效割的外部辅助问题，其变量不进入主问题。

适用范围是 `preprocessed` demand、origin assignment、aggregate flow、direct 路径、最多两单，并要求完整物理路径目录及完整分支行支持。不能用当前受限主问题已经生成的列来计算下面的极值。当前实验保持 `first_leg_consistency=false`。

## 1. 完整任务与首单分配之间的成本界

以 `r` 表示首单类型、`l` 表示出发基地，`k` 表示单单或双单任务。任务 `k` 的固定率为 `d_k`，其所有订单采用骑手配送的成本之和为 `g_k`；AA 任务计算两次 A 的订单成本。以 `P_kl` 表示所有从 `l` 出发的物理可行路径，允许任何返回基地。令

\[
 c_{kl}=\min_{p\in P_{kl}}\{c_p+F t_p\},\qquad
 S_{rl}=\sum_{k:\operatorname{head}(k)=r}d_k(g_k-c_{kl}),
 \qquad S^+_{rl}=\max\{0,S_{rl}\}.
\]

其中 `F` 是单位机队成本。完整路径已经包含服务、飞行、等待等现有成本；`F t_p` 计入忙碌机队成本。空载调位和额外资源限制在此界中被放松，故只会高估可节约成本。

原模型有 `v_rl=alpha_rl rho_l`，且每个正需求分支的流量为 `d_k v_rl`。因此，对所有原模型整数可行设计及其运营解，

\[
 Q\ge C_0-\sum_{r,l}S^+_{rl}\alpha_{rl}\rho_l
       +F\sum_l\frac{\rho_l}{1-\rho_l},
\]

其中 `C_0` 是全部骑手配送成本。将负的 `S_rl` 改为零只会降低这个成本下界。

若某个正需求分支没有物理路径，原模型对应的 `v_rl` 必须为零。实现将该组收益与负载系数置零，并在辅助 LP 中加入 `v_rl<=0`。这允许保留 `alpha_rl=1,rho_l=0` 的冗余编码；与先前路径支持的支配筛选不同，本次成本界保留所有原整数可行设计。

### 无新变量的队列弦界

记
\[
 S_l=\sum_r S^+_{rl}\alpha_{rl},\quad
 \bar S_l=\sum_rS^+_{rl},\quad
 g(s)=\max_{0\le\rho<1}\left\{s\rho-F\frac{\rho}{1-\rho}\right\}
 =\begin{cases}0,&s\le F,\\(\sqrt{s}-\sqrt F)^2,&s>F.\end{cases}
\]

`g` 在非负实数上凸，且 `g(0)=0`。因此对于 `0<=s<=Sbar_l`，
\[
 g(s)\le\eta_l s,\qquad
 \eta_l=\begin{cases}g(\bar S_l)/\bar S_l,&\bar S_l>0,\\0,&\bar S_l=0.\end{cases}
\]

得到一条线性成本界：
\[
 \boxed{\theta+\sum_{r,l}\eta_l S^+_{rl}\alpha_{rl}\ge C_0.}
\]

这是一条对原整数模型及其凸包有效的约束。不能把 `C0-g(s)` 的切线当成下界：该函数是凹函数，其切线通常是上界。本界也不宣称对旧版所有分数 McCormick 点有效；根松弛的标签必须区分原连续松弛和整数有效强化后的松弛。

## 2. 保留共同可用率的任务资源松弛

对每个完整任务计算逐柜负载下界和总负载下界：
\[
 a_{irl}=\sum_{k:\operatorname{head}(k)=r}d_k\min_{p\in P_{kl}}\ell_{ip},
 \qquad
 a_{rl}^{\Sigma}=\sum_{k:\operatorname{head}(k)=r}d_k
                \min_{p\in P_{kl}}\sum_i\ell_{ip}.
\]

必须分别计算总负载最小值；`min(sum)` 一般大于 `sum(min)`，不能用后者替代并误称相同强度。

给定战略设计 `x`，辅助问题最大化可节约成本
\[
 \max\ \sum_{r,l}S^+_{rl}v_{rl}-F\sum_l w_l
\]

并保留
\[
\begin{aligned}
 &0\le v_{rl}\le\alpha_{rl},\quad v_{rl}\le\rho_l,
 \quad v_{rl}\ge\rho_l+\alpha_{rl}-1,\quad0\le\rho_l\le z_l,\\
 &\sum_{r,l}a_{irl}v_{rl}\le C_i(x),\qquad
 \sum_{r,l}a^{\Sigma}_{rl}v_{rl}\le\sum_i C_i(x),\\
 &w_l\ge0,\qquad
 w_l\ge\frac{\rho_l-t^2}{(1-t)^2}\quad(t\in\mathcal T).
\end{aligned}
\]

最后一组是 `rho/(1-rho)` 的支撑直线，故只会低估空闲机队成本。对整数分配，前三条精确保持 `v_rl=alpha_rl rho_l`。每个原可行运营解均能映射到这个辅助 LP 的可行点，其可节约成本不大于 LP 最优值。因此，任何辅助 LP 的对偶可行解都是节约成本的全局上界，进而给出 `theta` 的全局线性下界。

这个 LP 不包含路径变量，不按当前开放航线筛选负载或成本系数。它的松弛程度仍可能较大，但返回的割在其他设计上也有效；不能把某个固定航线网络上单独计算出的容量界，未经条件化就当成全局割。

### 对偶证书与数值修复

全部辅助原始行写为 `A u <= b+B x`，原始变量非负。代码显式构造非负对偶变量 `pi` 和条件 `A^T pi>=c`，而不是把一个未认证的原始 LP 目标当作割截距。

检查并修复的顺序是：

1. 非负化所有价格；
2. 将每个基地的切线价格总和压到 `F` 以下，满足 `w` 列；
3. 通过 `v<=alpha` 的价格修补每个 `v` 列；
4. 通过 `rho<=z` 的价格修补每个 `rho` 列；
5. 重新检查全部列，只有无正违反量时才接受证书。

没有可用对偶解或预算为零时，返回可验证的安全价格而非未认证数值。路径成本/占用下界向下取整，节约系数及对偶 RHS 系数向上取整，最终再加小的数值松弛。静态界和动态割均不增加主问题变量。

## 3. 任务航线界

完整任务目录可以替代总订单率给出的统一大 M。对弧 `e`、首单 `r`、出发基地 `l`，定义
\[
 M_{erl}=\sum_{k:\operatorname{head}(k)=r}d_k
              \max_{p\in P_{kl}} n_{ep}.
\]

单源出发分配意味着每个首单只能选一个基地，且 `rho_l<=1`。因此服务流满足
\[
 f_e^{\mathrm{service}}\le\sum_r\max_l M_{erl}.
\]

必须在每个分支内先对路径取最大，再按固定任务率求和；不能只使用当前活动路径流量或受限列池。本轮对非基地—基地弧使用原总订单率界与上述任务界的较小值。直达空载调位仅占用基地—基地弧，后者保留原 `D(L-1)` 界；不以服务流界误删冗余空载环流。取最大值时包括所有返回基地，第二单不需要自身分配，重复弧按照真实重数计数。实现仅替换原有 link 行的系数，不增加变量或约束。

## 4. 验证与实验边界

`cpp/tests/task_savings_probe.cpp` 使用微型单元夹具，检查：L1/L2、单单/双单、AA、第二单 OD 无自身分配、跨基地返回、负收益、零首单率、无路径分支、低容量、预算耗尽回退及不完整目录拒绝。静态界和动态对偶割在其他整数固定设计的精确 SOCP 值以及这些点的凸组合上检查；完整整数 MISOCP 的目标在强化前后比较。

这些夹具只用于有效性验证，不是新生成的生产实验算例。生产比较使用已有的 TSL L1 M01 双单实例，四组依次为：路径支持基线；增加静态任务收益界；再增加任务资源割；再增加任务航线界。全部采用同一冻结二进制、600 秒、单线程、seed 43、1% gap，最多四组并行。保留输入、源码、命令、上下界、终止原因、运营解、原生与 Python 校验、候选及割记录。

本文件给出有效性推导，不预先承诺下界或运行时间改善。数值结论必须读取完成后的新批次报告。

验证记录：独立航线探针 `outputs/task_cost_validation_20261027/task_airline_probe.json` 已通过四组 L1/L2 × K1/K2，共 280 次 assignment–arc 组合检查；完整整数目标最大差为 1.223e-8，第二单无自身分配的固定运营目标最大差为 5.025e-8。

测试过程中，CPLEX 在一个对称的微型双单 MISOCP 上曾独立报告两个相差一条航线成本（0.01）的 `Optimal` 值。原模型较低的解扩展 epigraph 后满足全部强化约束，最大线性残差约 3.3e-9；这一诊断保留在 `task_savings_unseeded_misocp_diagnostic.jsonl`。探针因此显式交叉检查原最优点，并将该已经核验的点提供给强化模型作为起点，再比较求解结果；没有放宽目标一致性的阈值，也没有修改生产求解参数。

任务成本探针最终通过 9 组夹具、69 次固定设计精确 SOCP、2178 次跨设计/凸组合割检查和 15015 个队列弦样本。最大割违反量为 0，完整整数模型目标最大差为 3.864e-7；正服务的第二单无自身分配见证在普通双单及跨返回夹具中均被明确检查。完整结果保存为 `outputs/task_cost_validation_20261027/task_savings_probe.json`。

额外检查采用生产集成测试输出的实际静态系数，对上一轮的 338 个 L1 候选重新计算下界。全部候选的运营成本界为 4054.2263–4090.9184，已超过原总成本上界 3773.6314；旧 incumbent 则满足成本界。此结果保存为 `old_candidate_static_bound_audit.json`，它是对旧候选的拒绝能力检查，不是新算法的全局下界结果。
