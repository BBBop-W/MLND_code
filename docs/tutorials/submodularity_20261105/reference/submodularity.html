次模性与队列成本割

概念判断或作用
模块函数加入元素的边际与已有集合无关，例如 Σᵢ∈A wᵢ。
次模函数对 A⊆B、i∉B，Δᵢf(A)≥Δᵢf(B)；比较带符号的边际。
超模函数上述不等式方向相反；−f 次模当且仅当 f 超模。
凹函数复合g 凹、wᵢ≥0 ⇒ f(A)=g(Σᵢ∈A wᵢ) 次模；不要求 g 递增。
前缀边际割沿任一排列计算边际 Δ；若 f(∅)=0，则 Σᵢ∈A Δᵢ≤f(A)。
贪心分离按分数变量降序排列，取得该次模不等式族中最强的一条。
Lovász 延拓次模函数对应凸的分段线性延拓；它与自然连续公式可以不同，只需在二元点一致。

MLND 中对应什么

ΦF(s)=max0≤ρ<1{sρ−Fρ/(1−ρ)} 为凸函数。非负任务收益系数 Sᵣ 下，成本项 f(A)=−ΦF(Σᵣ∈A Sᵣ) 次模，而正的节约额超模。用这些成本边际生成线性下界，可以加强整数主问题。

不能据此推出完整运营值函数 Q 次模，也不能把分数点上的代数改善当作生产求解的最终下界改善。
