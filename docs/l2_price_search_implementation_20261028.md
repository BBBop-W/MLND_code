# L2 原生资源价格搜索与目标主问题精化

本轮承接 `l2_next_cut_math_20261028.md` 的价格搜索方案与 `l2_next_bounds_and_ub_audit_20261028.md` 的近目标认证方案。实现范围是两个开关组成的一个算法包；两基地联合割留待后续。保留已有上界搜索，正式比较不导入历史 incumbent。

## 原生 SOCP 资源价格与 EPI 搜索

从已经求解的普通 SOCP 读取的行乘子中，取柜容量价格 `mu=-pi_capacity`、航线容量价格 `eta=-pi_link`、流量平衡势 `lambda=-pi_balance`。沿用普通证书已有的行符号投影；将所有平衡势减去最后一个基地的势。规范化分支门控价格 `tau=0`。不增加对偶求解器调用，不以原生对偶目标作为新割截距。

每次外层根节点或整数 recourse 返回后，用该次普通证书的资源价格作为端点 B；端点 A 为当前割池在实际主问题点上的最强资源价格。若池中只有静态 S+，A 取零资源价格。以 `p(t)=(1-t)p_A+t p_B` 搜索；两端点及最多五个内点，每次选择当前最佳观测值旁较长区间的中点。缓存端点无需再次扫描，但每一个新候选必须完整扫描路径域，重新构造 signed B、负费用空驶修正、缺失分支 AND 门控和 EPI 行。

数学上，固定二元 assignment 的价格函数是仿射拉格朗日函数的下包络；在固定分数 assignment 处取整数凸包闭包，仍是对价格的凹函数。这给出一维搜索依据。实际有限扫描只是选择合法价格的启发式，不声称找到价格最优解；有效性始终由每个候选的完整域构造保证。

搜索期间使用临时 profile，仅将胜出的新价格加入池，保护已有最强资源端点；若容量不足可返回完整证书而不缓存。任何扫描未完成或数值失败均回退到调用前最强行。返回值与旧池逐项比较，因此完成的局部搜索不会降低该分离点的已有界；这不保证有限总时间内的全局 LB 或 UB 单调改善。

每次最多 0.5 秒，累计额度为总时间的 2%。行只加入主问题；全局 LB 必须等主问题重新优化后读取。新开关 `--queue-price-search` 要求 `--queue-polymatroid-cuts`。

## 临近目标的有界主问题认证

目标下界为 `T=UB-g*max(1,abs(UB))`。仅在当前 gap 大于 g 且不超过 1.25g、已有至少三次 supported CG、至少三次下界停滞、距上次精化结束至少 30 秒、且当前已验证的主问题候选值 C 大于 T 时触发。

此次求解使用 `min(旧 MIP 相对容差, 0.5*(C-T)/(1+abs(C)))`；T 向上舍入，容差向下舍入。单次最多 5 秒，累计额度为总时间的 2%，且不能越过总截止时间。容差在调用后恢复。求解可能找到更低的主问题候选，因此这个容差只提供有根据的尝试，并不保证达到目标界。

精化只用 CPLEX 的 certified best bound 更新全局 LB。候选目标仅用于触发与容差计算，绝不作为 LB；若后一次没有有效候选，保留前一次已验证候选。原可行性、recourse 证书和最终 gap 容差不变。新开关 `--target-master-refinement` 要求 Benders 的 `--search-scheduling`。

## 验证与对照

- 公开接口手算价格混合：中间价格严格强于两个端点和原池。
- 原完整物理 SOCP 固定设计与跨可行点检查；实际原生行价格导出后再做完整域搜索。
- 零预算、数值失败、扫描上限、相同端点、饱和池保护端点测试。
- 真实 M08 数字推导的目标容差与非法、过远、已达标等拒绝边界测试。
- K1/K2 全流程，确认无新增主问题运营变量、无新增普通对偶优化、LB 不超过完整模型可行 UB。
- M01/M07/M08 六次新运行：同二进制、输入、seed=43、单线程、600 秒、1% 目标。旧版为当前 queue 算法；新版只额外启用上述两个开关。最终比较完成状态、可行性、UB、认证 LB、gap、时间和独立割证书审计。

两个新开关默认关闭。完整路径证书重建与跨点审计通过才视为完成；性能结论以本轮冻结对照结果为准。
