# MLND 加速扩展：实现、数学边界与验证

2026 年 11 月 5 日。本文对应在[研究方案](fixes_and_acceleration_plan_20261105.md)之后实施的四类扩展：精确模型缩减、运营状态复用、结构化邻域，以及定价与割管理。实现版本为 `accelerated-20261105`。这是一组已通过小型正确性检查的新算法配置，尚不是经过大实例性能对照的新 baseline。

## 1 实现范围与配置

| 方向 | 已实现机制 | 独立开关 |
|---|---|---|
| 精确模型缩减 | 精确零任务率列不进入运营模型；消去 head/group head 并恢复原输出格式 | `eliminate_zero_task_columns`、`compact_task_heads` |
| 运营状态复用 | 完整事件图缓存；同一整数设计的 RMP、原生求解器及数值恢复状态持久化 | `cache_pricing_graph`、`persist_recourse_model` |
| 结构化邻域 | 为短名单缺失分支补路径；任务状态与容量档位的独立组半径 | `primal_support_completion`、`grouped_local_branching` |
| 定价与割管理 | 平滑价格发现列、原对偶完整认证；有效割精确去重、休眠和恢复 | `stabilized_pricing`、`cut_pool_deduplication`、`cut_pool_management` |

新 preset 在 `alns-20261030` 的配置上启用表中九个开关。已有 preset 和无 preset 的低层默认值没有加入这些新开关；所有开关都可以用 `--disable NAME` 单独关闭。缩减模型不改变物理目录、任务率或路径 ID。跨设计复用 RMP、独立连续根入口跨调用缓存、隐式生成尚未注册的物理路径、跨模块预算学习及 CG→ALNS 候选信息反馈，不在本轮实现范围内。

ALNS 继续限定为双基地 K2 的固定任务 aggregate 模型。新配置直接用于这个范围；对 K1 或其他基地数，关闭 `primal_alns` 和 `primal_support_completion` 后，可以使用普通 Benders 配合其余通用扩展。压缩 head 不支持共同首段一致性模型，CLI 会拒绝这一组合。

```sh
# 独立构建目录，不覆盖已有试验使用的可执行文件。
make -C cpp -j1 BUILD_DIR=build-accelerated-20261105

# 在现有命令中选择新版本；以下仅展示配置片段，不启动试验。
# L2 K2: --preset accelerated-20261105 --k 2
# K1:    --preset accelerated-20261105 --k 1 \
#          --disable primal_alns --disable primal_support_completion
```

新参数初值为：平滑权重 0.5、每 4 轮一次强制原对偶定价、首单组半径 4、柜容量组半径 2、活跃割目标 256、最短非活跃年龄 8。它们是可复现的初始设置，未宣称经过调优。完整解析与校验见 [solver_presets.cpp](../cpp/src/solver_presets.cpp)，命令行标量参数使用对应的连字符名称，例如 `--pricing-exact-interval`、`--cut-pool-active-limit`。

## 2 精确模型缩减

### 2.1 删除被强制为零的运营列

固定分支 \(b\) 的任务等式和非负性给出

\[
\sum_{p\in\mathcal P_{rlb}}f_p=\nu_{rb}v_{rl},\qquad f_p\ge0.
\]

当且仅当存储的固定任务率 \(\nu_{rb}=0\) 时，该分支的每个 \(f_p\) 被强制为零。实现将其有效上界设为零，初始建模和逐列／批量增列均跳过该列。完整目录和分支行仍保留；没有把小正率按容差清零，也没有在任务预处理之前筛掉用于计算成本与支持的路径。

这个界同样作用于定价和辅助对偶的遗漏列处理。零上界变量不会贡献遗漏列修正，正率分支继续接受完整域定价。其有效性来自原任务等式的推论，而不是把未搜索的路径假定为无效。原始解按稳定路径 ID 补零即可恢复；已有解若在不存在的列上含正流，不会未经检验就被当作合法新模型暖启动。

### 2.2 通过代入消去 head 变量

压缩仅在 `preprocessed + origin + aggregate` 且没有共同首段一致性时生效。原模型中

\[
h_j=\sum_{p:j(p)=j}f_p,\qquad
g_{rl}=\sum_{j\in J_{rl}}h_j,\qquad
g_{rl}=H_rv_{rl}.
\]

实现删除 \(h_j,g_{rl}\) 和对应定义行，但**保留每个首单／基地的总量行**，改写为

\[
H_rv_{rl}-\sum_{p:\operatorname{head}(p)=r,\operatorname{origin}(p)=l}f_p=0.
\]

这比直接删除总量行更保守：没有初始段的空支持组仍满足 \(H_rv_{rl}=0\)，并保留存储的 \(H_r\) 与各分支率相加时可能存在的浮点差别。通常 \(H_r\le\lambda_r\) 与 \(v_{rl}\le1\) 已蕴含原 head 上界；若手工输入或舍入边界出现 \(H_r>\lambda_r\)，额外保留 \(H_rv_{rl}\le\lambda_r\)。

从原模型投影到压缩模型是直接代入。逆映射按路径流求和恢复 \(h_j,g_{rl}\)，所有非负性与上界仍成立，所以整数设计、分数设计和限制列集下的可行投影与目标均保持一致。输出仍包含原维度的 segment head，既有独立验证器和解格式保持可用。

实现见 [formulation.hpp](../cpp/include/mlnd/formulation.hpp)、[formulation.cpp](../cpp/src/formulation.cpp)、[output.cpp](../cpp/src/output.cpp) 及 [heuristics.cpp](../cpp/src/heuristics.cpp) 的原始点提升。

## 3 图缓存与同设计 RMP 续算

事件图由一个求解过程显式持有，缓存最多一个完整图。缓存身份使用输入及不可变初始段数据的精确快照，包含任务率，不依赖相同维度、名称或对象地址。构造中断的图不会发布。各 oracle 独立绑定自己的输入和路径集合，避免缓存留下错误的对象指针。

RMP 缓存最多保留一个普通整数设计的 Formulation、NativeSolver、列成员、数值恢复配置和价格中心。相同设计恢复时只追加合法新列，再重新优化、读取当前原生对偶和认证。换设计、模型参数、输入、已注册列负载或求解器配置时冷建；正常的路径追加可以继续复用。异常退出不归还可能不一致的状态。数值恢复后若新增列，保留原来的冷重建与 profile 重置机制。

缓存不保留可直接复用的 Cut 或最优性证书。上一时间片的对偶、约化成本或完整性状态不能作为下一时间片的新证书。快照保存时间计入 `sub.wall`，并单列 `state_cache_snapshot`；因此恢复成本和保存成本均进入实际调用统计。

主 Benders 内的整数、分数根、初始及邻域运营调用共享事件图；RMP 状态仅交给普通整数主循环和待续设计，启发式调用不会挤掉待续模型。独立 `solve_continuous_cg` 公共入口尚未跨调用共享这个图缓存。这里验证的是模型与构建状态的复用，不是 CPLEX 对 SOCP 必然提供特定的数值热启动加速。

## 4 邻域覆盖与组距离

### 4.1 按需补齐缺失分支

修复块先使用原代表路径短名单。当某个首单／出发基地／正任务分支缺少避开强制关闭资产的路径时，单次扫描注册物理路径池，为所有缺失分支寻找见证。当前固定任务入口要求完整物理目录，因此在通常运行中这就是从完整目录补齐短名单。

代码明确区分 `paths.complete` 和仅表示行支持的 `support_complete`。目录不完整或扫描未完成时，记录 `unknown_support`，不会将缺见证解释成全域不可行。仍无支持的出发状态可以只在本次修复中禁用，保留其他出发状态及骑手服务；不删除任务等式。无强制关闭的强化邻域保留 incumbent，强制关闭操作则建立相应依赖闭包。

### 4.2 战略组半径

首单从一个基地迁移到另一个基地计一次状态改变；柜容量由一档切换到另一档也计一次。对中心状态 \(\bar a_r\)，其距离为

\[
\delta_r(\alpha)=
\begin{cases}
\sum_l\alpha_{rl},&\bar a_r=0,\\
1-\alpha_{r,\bar a_r-1},&\bar a_r>0.
\end{cases}
\]

柜容量组同理。修复中分别约束任务距离总和不超过 \(k_R\)、容量距离总和不超过 \(k_H\)，航线与连续运营按原模型重配。普通正半径局部分支与 regular ALNS 均接入这两个半径；startup 不施加组半径，`radius=0` 保持原先固定全部受选二元位的兼容语义。

这些邻域仍是原可行域的子集。解须经过原模型和独立物理验证才能更新 UB；局部 best bound 不进入全局 LB。组半径严格使用配置值，不会默默扩大。因此某次需要更多柜点同时改变的操作可能在给定半径下无解，这属于受限搜索范围，不是原问题无解。

## 5 稳定化发现列与完整认证的分工

使用历史中心和当前原生对偶构造

\[
\widetilde\pi^k=(1-\omega)\widetilde\pi^{k-1}+\omega\pi^k.
\]

平滑价格只用于寻找候选列。每个候选重新计算原对偶下的 \(c_p-a_p^\top\pi^k\)，只有小于负容差者才进入加列集合。第 1、\(1+m\)、\(1+2m\) 等轮次，以及平滑候选经原价格筛选后为空时，执行原对偶完整定价。

发现列的返回对象明确设置 `discovery_only=true`，不能给出遗漏列修正、弱 Benders 割、连续下界或终止证书。只有 `exact_pricing` 且原价格定价完整的轮次进入原认证链。其作用是改变列发现顺序，不缩小物理域，也不将 LP 稳定化的收敛定理直接用于 SOCP。

平滑可能减少振荡，也可能增加一次无用定价；微型检查中甚至可能多一轮 CG。它目前有正确性与可回退证据，没有总体速度提升证据。实现及核查入口见 [pricing.cpp](../cpp/src/pricing.cpp)、[benders.cpp](../cpp/src/benders.cpp) 和 [pricing_state_probe.cpp](../cpp/tests/pricing_state_probe.cpp)。

## 6 有效割去重、休眠与再激活

割池只接收已有认证且无条件的仿射运营割。完全相同的 RHS 与系数可以去重，近似相等、近似平行或仅在样本点较弱都不会被当作冗余。条件割与其他资源割族保持原处理方式。

对长期非绑定的割 \(a^\top z\ge b\)，按变量界计算向外舍入的

\[
\underline b\le\min_{\ell\le z\le u}a^\top z.
\]

休眠时暂将 RHS 改为 \(\underline b\)，成为冗余行。这样不移动行号，不破坏其他分离器与原生求解器的映射；**没有物理删除行，也不声称释放了全部行存储内存**。活跃数量是软目标，绑定或未达保护年龄的割不会为凑数而被休眠。

每个新主问题候选都检查休眠割；违反时恢复原 RHS，并重新求主问题后再使用候选。待续运营期间不休眠，结束时恢复全部原割。弱化主问题得到的下界依然有效，历史认证 LB 继续取最大值；局部割值没有直接成为全局下界。可检验实现见 [certified_cut_pool.hpp](../cpp/include/mlnd/certified_cut_pool.hpp)。

## 7 验证结果与尚未验证的事项

验证使用独立 release 构建 `/tmp/mlnd-acceleration-20261105-build`，编译参数含 `-O3 -DNDEBUG -ffp-contract=off`，串行编译，小型求解使用单线程。最终 16 组自包含探针全部通过，新 CLI 参数解析检查通过，编译未检出 warning 或 error。未修改原试验二进制、启动脚本或输出目录，未读取正在运行试验的结果。具体命令、各探针结果及修改文件指纹保存在[验证清单](acceleration_20261105.validation.json)。

主要验证包括：

- K1/K2 的整数及分数固定设计，比较原／缩减 SOCP 目标，双向恢复可行点，检查空支持、精确零与极小正率、原格式暖启动及增列一致性。
- 对 6,561 个中心—候选状态组合穷举组距离，并检查短名单外见证、局部出发状态禁用、固定区域和关闭资产依赖。
- 完整定价与穷举的 8 组差分，图构建中断不发布，输入／选项／注册列变化导致缓存失效；同一设计真实二次求解，以及受控数值 profile 的保留与增列重建。
- 验证平滑发现对象不能认证；完整 CG 与原流程目标一致。
- 小型割模型休眠后目标由 3.1 放松到 0.1，恢复后回到 3.1，确认休眠方向与再激活有效。
- K1 普通 Benders 与 K2 新 ALNS 配置的组合验证，并将结果送回原完整模型恢复；另运行已有原生对偶、定价、上下界及 ALNS 集成回归。

独立复核和回归还修正了两处计时细节：状态快照保存纳入 CG 总调用时间；连续根阶段的累计时间与单阶段记录使用同一个完成时刻，避免两次取时使累计值略小于单阶段值。后者由既有 `lb_integration_probe` 的断言发现，修复后重新通过。

缩减专用的微型例给出下列实际矩阵规模；这不是生产实例统计，也不是速度测量：

| 场景 | 原变量数 → 新变量数 | 原行数 → 新行数 | 删除的零率列 |
|---|---:|---:|---:|
| K1，整数／分数固定设计 | 81 → 61 | 155 → 135 | 0 |
| K2，整数／分数固定设计 | 145 → 101 | 163 → 143 | 24 |

所有上述检查仅针对小型构造例及相应回归。组合例在很少的外层迭代内结束，没有触发真实长时 ALNS 周期，也没有达到默认割池休眠年龄；状态续算和割休眠因此使用单独可控检查覆盖。尚未进行大实例消融、峰值内存比较或达到目标 gap 的时间对照，不能据此宣称总体提速或替代现有已验证 baseline 的成绩。
