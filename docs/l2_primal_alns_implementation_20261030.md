## 实现边界

3–6 秒 repair 和 180 秒上界额度是调度额度；CPLEX 原生构造及完整物理验证在可检查边界停止，单次不可中断工作可能产生超时偏差。全部实际耗时计入共享预算，输出 `budget_overrun_seconds`，不另赠初始化时间。全局仍使用原端到端 deadline。

支持库和邻域用稀疏物理索引；已接受解仍复用现有密集 JSON/原验证接口，只在接受、验证或导出时处理，不为每个候选重新复制整个物理目录。进一步改为稀疏运营点属于后续效率改进。目录不完整、缺少短名单见证或限时无解都作为未知/受限域状态，不推断全域不可行。
