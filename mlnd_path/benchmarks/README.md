# 实验记录

- `multiscale_20260914/`：正式四规模、两种子、四算法对照，32 次运行。
- `stress_20260914/`：4 基地／8 柜／24 OD／2 远程换电站，81,744 条服务列，两种加强算法的扩展测试。
- `validation_tests.xml`：交付前 13 项独立测试的结果。
- `development_trials.json`：早期循环／lazy／核心点选割的压缩开发记录，预算和代码版本与正式对照不同，单独保存。

每个正式目录包含 `config.json`（参数、环境、计算模块哈希）、`summary.json`、实例元数据及逐算法结果。逐算法文件保存实际流量、选址、上下界、时间和可用的迭代轨迹。

总求解预算包含该算法的矩阵准备、主问题、连续求解和定价。路径预处理单独计时，端到端耗时包含预处理与求解。运行超时后的数值返回、解提取和结果核对可能使实测壁钟时间略高于设定预算。
