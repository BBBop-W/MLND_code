纯激活设施下的解析路径投影与全局多割

日期：2026-09-14。对应实现：mlnd_path/analytic_benders.py。本说明固定当前费用、随机运营时间解析均值和机队线性计价，不增加新业务假设。

1. 固定什么以后，路径分配能够分离

用 (g) 临时统称两类已经存在的路径组：服务组 (g=(od,,m)) 和空程组 (g=(,m))。这个简写只用于本推导，代码仍保留两类独立键。

设 (T_g) 是主问题决定的组总流量，(P_g) 是该组的全候选列，(c_p) 为代码中的边际路径成本。服务列包括运营成本、减去全程骑手基准成本、加上单位机队费乘平均占用时间；空程列包括运营成本与机队占用成本。因此，服务列的 (c_p) 可以为负。

对每个设施 (h)，(y_h{0,1}) 表示开放；(a_{hp}=1) 表示路径 (p) 需要该设施。这里包括两端基地、取餐柜、目的柜和实际使用的换电站。固定整数 (y) 后，开放可行列集合为

[ P_g(y)={pP_g:a_{hp}y_h h}. ]

在主问题保留 ()、idle、OD 基地对选择以及 (T_g) 后，OD 可用率关系、基地流量守恒、空程请求时钟全部由主问题确定。路径构成影响的余下行只有设施激活。

2. 当前开放设施的 gate 确实不会成为容量瓶颈

data.py 的系数为

[ M={od}h{od}, M^E=|L|, MK=4M+2ME. ]

所有服务流量之和不超过 (M)，所有空程流量之和不超过 (M^E)。solver.py 的柜激活行按 ({i,j}) 集合记录一次，因此每个柜的总服务使用量最多为 (M)。

换电行使用实际访问次数。当前资源标签生成器中，同一阶段内返回同一换电点会恢复相同满电状态，并增加正飞行／换电成本和时间，因此被此前标签支配。服务任务有三个阶段，一个换电点最多在各阶段使用一次；空程只有一个阶段。生成器因此满足服务列每站次数不超过 3、空程每站不超过 1，低于 (M^K) 使用的 4／2 保守系数。

解析程序另外按实际输入逐站检查充分条件：

[ {od}h{od} {p:,pod}a^{}{hp} + {r:,r}a^{}_{hr} M^K. ]

若输入列不满足这个冗余容量条件，解析程序要求使用一般路径 LP。现有按 OD／空程起点拆开的加强 gate 使用 0/1 设施访问关联，它们在设施开放时同样被对应总流量上界蕴含。

所以，在当前整数设施设计下，柜与换电 gate 的作用就是允许或禁止路径。不同组共享一个开放设施不会争用有限容量。

4.1 在当前整数设施设计处使割达到最优值

设当前设计为 (y)，且本组存在开放列。取 (q_g=q_g(y))，并令所有当前开放设施的 (_{gh}=0)。每条费用低于 (q_g) 的列至少经过一个当前关闭设施。

最简单的构造是对所有当前关闭设施取

[ {gh}={0,q_g-{pP_g}c_p}. ]

实现采用更细的构造。对便宜不可用列 (p)，令 (C_p) 为它需要且当前关闭的设施集合，将费用缺口均分后逐设施取最大值：

[ {gh}= {p:,hC_p} . ]

每条列从自身经过的关闭设施得到的补偿至少为自己的费用缺口，故满足全部列约束。与任何便宜不可用列无关的关闭设施系数为零。代码随后重新扫描所有候选列，记录最小检验数并加入浮点残差修正。

由于 () 在开放设施上为零、(y) 在关闭设施上为零，当前设计的惩罚项为零，所以 (AC) 在该设计下成为

[ _gq_g(y)T_g. ]

这条割对同一设施设计下全部连续流量值都达到最优路径成本，而不只是在产生割时的单个 (T_g) 处成立。

4.2 哪些域上有效

(AC) 对所有整数设施设计和所有满足主问题的连续流量都有效，也对它们的凸组合有效。上述逐组激活 LP 下界在 (y) 上也成立。

相对于旧模型中仅有总量／按 OD 的激活行，逐基地对的 (U_g y_h) 是新增整数有效加强。它可能收紧旧模型的分数设施松弛。因此使用这些割时，以原整数模型的下界为验证对象，并用完整整数可行解检验上界。

成本辅助变量 (_g) 允许为负，初始线性下界使用

[ g({pP_g}c_p)T_g. ]

全部成本通过 (_g_g) 汇总。

6. 缓存与有限设计性质

一次 oracle 对当前整数设施 pattern 的所有路径组计算最便宜开放列与成本／可达性割。该结果不依赖 OD 基地对二元变量的具体取值，也不依赖 () 或流量 (T)，所以缓存键只需设施开放位图。

当同一设施 pattern 在分支搜索中再次出现，仍须逐组检查当前成本估计、流量是否违反对应割，并向 callback 重新提交必要的 lazy 约束。缓存负责避免重复全列计算，不替代 lazy 约束的逐候选执行。

若忽略浮点容差，在每个设施 pattern 处加入全部组的成本／可达性割后，这个 pattern 下所有连续运营量的路径投影均已刻画正确。设施 pattern 数有限，给出了不同于“逐 (,T) 点反复求子问题”的有限结构。

7. 与一般 LP＋CG 的比较位置

两种方法沿用相同整数模型和含 idle 锥的聚合主问题。一般 LP＋CG 可以处理不同组之间的真实共享容量；当前解析法利用这些 gate 纯属设施激活的结构，消除实际路径 LP 求解。

因此对比应同时报告：主问题耗时、oracle 调用与缓存命中、独立设施 pattern 数、成本割和可达性割数量、上下界、完整矩阵复核残差。未来加入硬机队上限或实际换电吞吐容量时，路径间资源权衡会重新出现，需要恢复相应联合分配子问题。
